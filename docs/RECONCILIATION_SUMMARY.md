# QuickBooks Reconciliation - BrightFix Home Services LLC

Generated by connecting the pipeline to a real QuickBooks Online sandbox,
running the full pipeline end to end (upload → classify → sync → reconcile)
against all 195 classified transactions, and pulling QuickBooks' own
cash-basis Profit and Loss report for the same period via the API.

Raw comparison data: `reconciliation_output.json` (this app's own parsed
comparison, as returned by `GET /api/reconciliation/full`).
QuickBooks' own report, exported directly from the QBO UI: `qbo_profit_and_loss.pdf`.

here required real debugging against the live sandbox, not just a clean
first run - see `docs/AI_USAGE.md` for the full account of what was found

gap, a data-loss incident from a local environment misconfiguration and its
cleanup, a sign-convention mismatch between this app and QuickBooks' report
format, and a parser gap around how QuickBooks represents a parent
account's own balance) - plus the manual work of clearing QuickBooks'
pre-loaded sample company data out of the sandbox so the comparison was
apples-to-apples.
